1처음 등록 신청하기

처음 한 번만 하시면 됩니다. 담당자가 확인하면 로그인하실 수 있어요.

  1. 휴대폰으로 셀 케어 주소를 엽니다.
    tlc-cell-care.vercel.app
  2. 첫 화면 아래 「처음 오셨나요?」에서 등록 신청하기를 누릅니다.
  3. 이름과 자주 확인하시는 이메일을 적고 신청합니다.
  4. 「신청이 접수되었습니다」가 나오면 끝입니다. 담당자가 확인한 뒤 승인해 드립니다.
이름은 교회에서 부르시는 이름 그대로 적어 주세요. 명단과 맞춰 보고 승인합니다.
이미 등록된 분이라면 신청 없이 바로 로그인하셔도 됩니다.

2로그인하기

비밀번호는 없습니다. 이메일로 받은 숫자 코드로 들어갑니다.

  1. 등록한 이메일을 적고 로그인 메일 받기를 누릅니다.
  2. 메일함에서 방금 받은 로그인 메일을 열어 숫자 코드를 확인합니다.
    메일이 안 보이면 스팸함(광고 메일함)도 확인해 주세요.
  3. 셀 케어 화면으로 돌아와 숫자를 입력하고 코드로 로그인을 누릅니다.
한 번 로그인하면 그 휴대폰에서는 계속 로그인된 채로 열립니다. 다만 다른 인터넷 앱이나 다른 기기에서 열면 코드를 한 번 더 받아야 해요.

3홈 화면·PC에 설치하기

앱처럼 아이콘을 눌러 바로 열 수 있고, 알림도 받을 수 있습니다. 쓰시는 기기를 골라 주세요.

  1. 사파리(Safari)로 셀 케어를 엽니다.
    카카오톡·네이버 앱 안에서는 추가할 수 없어요. 아래 '자주 묻는 질문'을 참고해 주세요.
  2. 화면 아래의 공유 버튼 을 누릅니다.
    공유 버튼이 안 보이면 주소창 옆 「⋯」를 먼저 누른 뒤 「공유」를 누르세요.
  3. 목록을 위로 밀어 홈 화면에 추가를 누릅니다.
  4. '웹 앱으로 열기'가 보이면 켜 둔 채로, 오른쪽 위 추가를 누릅니다.
  5. 홈 화면에 생긴 셀 케어 아이콘을 눌러 열고, 한 번 더 로그인합니다.
아이폰은 홈 화면 아이콘이 사파리와 따로 움직여서, 아이콘으로 처음 열 때 코드를 한 번 더 받아야 합니다. 그 뒤로는 계속 아이콘으로 여시면 됩니다.

크롬(Chrome)으로 여실 때

  1. 크롬으로 셀 케어를 엽니다.
  2. 오른쪽 위 「⋮」(점 세 개)를 누릅니다.
  3. 홈 화면에 추가 또는 앱 설치를 누릅니다.
  4. 설치(또는 추가)를 누르면 홈 화면에 아이콘이 생깁니다.

삼성 인터넷으로 여실 때

  1. 아래쪽 「≡」(줄 세 개) 메뉴를 누릅니다.
  2. 현재 페이지 추가 → 홈 화면을 누릅니다.
  3. 추가를 누르면 홈 화면에 아이콘이 생깁니다.
메뉴 이름은 휴대폰마다 조금 다를 수 있어요. '홈 화면', '앱 설치'라는 말이 들어간 메뉴를 찾으시면 됩니다.

크롬(Chrome)으로 여실 때

  1. 크롬으로 셀 케어(tlc-cell-care.vercel.app)를 엽니다.
  2. 주소창 오른쪽 끝의 설치 아이콘 을 누릅니다.
    안 보이면 오른쪽 위 「⋮」 → 「전송, 저장 및 공유」 → 「페이지를 앱으로 설치」(또는 「앱 설치」)를 누르세요.
  3. 설치를 누르면 셀 케어가 따로 창으로 열리고, 시작 메뉴에 아이콘이 생깁니다.

엣지(Edge)로 여실 때

  1. 엣지로 셀 케어를 엽니다.
  2. 오른쪽 위 「⋯」 → 앱 → 이 사이트를 앱으로 설치를 누릅니다.
  3. 설치를 누릅니다.
작업 표시줄의 셀 케어 아이콘을 마우스 오른쪽으로 누르고 「작업 표시줄에 고정」을 고르면 다음부터 한 번에 열립니다. 설치한 앱에서 처음 열 때는 로그인 코드를 한 번 더 받아야 할 수 있어요.

사파리(Safari)로 여실 때

  1. 사파리로 셀 케어(tlc-cell-care.vercel.app)를 엽니다.
  2. 화면 맨 위 메뉴 막대에서 파일 → Dock에 추가를 누릅니다.
    공유 버튼 안에도 「Dock에 추가」가 있습니다. macOS Sonoma(14) 이상에서 됩니다.
  3. 추가를 누르면 Dock에 셀 케어 아이콘이 생깁니다.

크롬(Chrome)으로 여실 때

  1. 주소창 오른쪽 끝의 설치 아이콘을 누르거나, 「⋮」 → 「전송, 저장 및 공유」 → 「페이지를 앱으로 설치」를 누릅니다.
  2. 설치를 누르면 Launchpad와 Dock에서 열 수 있습니다.
Dock의 아이콘으로 처음 열 때는 로그인 코드를 한 번 더 받아야 할 수 있어요. 알림은 아이콘으로 연 셀 케어에서 「알림 받기」를 누르면 맥 알림으로 옵니다.

4알림 받기

보고서 마감과 확인할 일을 휴대폰 알림으로 알려 드립니다.

  1. 홈 화면의 셀 케어 아이콘으로 열고 로그인합니다.
  2. 화면의 「셀 케어 알림을 받으시겠어요?」에서 알림 받기를 누릅니다.
  3. 휴대폰에서 묻는 창이 뜨면 허용을 누릅니다.
  4. 「이 휴대폰으로 셀 케어 알림을 받고 있습니다」가 보이면 준비 끝입니다. 테스트 알림 보내기로 확인해 보셔도 좋아요.

자주 묻는 질문

코드를 또 받으라고 나와요

로그인은 인터넷 앱마다 따로 기억됩니다. 카카오톡에서 링크를 누르면 카카오톡 안의 작은 화면으로 열려서 매번 새로 받아야 할 수 있어요. 홈 화면 아이콘으로만여시면 다시 받을 일이 거의 없습니다.

카카오톡에서 링크를 눌렀어요

오른쪽 위(또는 아래)의 「⋯」를 누르고 다른 브라우저로 열기(아이폰은 「Safari로 열기」)를 눌러 주세요. 그다음 ③ 홈 화면에 추가를 하시면 됩니다.

메일이 오지 않아요

스팸함(광고 메일함)을 먼저 확인해 주세요. 1~2분 기다린 뒤에도 없으면 이메일 주소에 오타가 없는지 확인하고 다시 받아 주세요. 등록 승인 전이라면 메일이 가지 않습니다.

등록 신청을 했는데 로그인이 안 돼요

담당자가 승인한 뒤부터 로그인하실 수 있어요. 신청할 때 적은 이메일과 같은 주소로 로그인해 주세요. 오래 걸리면 담당 교역자에게 말씀해 주세요.

알림이 오지 않아요

아이폰은 홈 화면 아이콘으로 연 셀 케어에서만 알림을 받을 수 있어요. 휴대폰 설정 → 알림에서 셀 케어가 꺼져 있지 않은지도 확인해 주세요. 다른 계정으로 로그인했다면 알림 받기를 한 번 더 눌러 주세요.
